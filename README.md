## ▶️ Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o arquivo desejado. Por exemplo:

```bash
python "subtração.py"
```

Alguns arquivos têm espaços e o prefixo `#` no nome; por isso, mantenha as aspas ao executá-los. Os programas são independentes, então rode um exercício por vez.

## 🎯 Conceitos praticados

- Entrada de dados com `input()`.
- Conversão de texto para números com `int()`.
- Operadores aritméticos.
- Exibição de resultados com `print()`.

## 🛠️ Próximas melhorias
